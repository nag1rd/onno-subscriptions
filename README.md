# Сервис подписок на onno

Сервис управления клиентами, тарифами, платежами и подписками. Стек: **Java 21, Spring Boot 3.4.4, onno 3.4.1, H2**. Схему БД, стандартный REST API и интерфейс генерирует onno из Java-метамодели.

## Запуск

Нужны JDK 21 и Maven 3.9+. Из папки проекта выполните:

```bash
mvn clean verify
mvn spring-boot:run
```

Откройте [http://localhost:8080/ui](http://localhost:8080/ui). Локальный вход: **admin / admin**. Пароль настраивается переменной `APP_ADMIN_PASSWORD`.

Данные сохраняются в `data/subscriptions.mv.db`. Остановка — `Ctrl+C`;

## Возможности

- Справочники клиентов и тарифов.
- Платежи: «Банковская карта» и «СБП».
- Подписки с несколькими тарифами и количеством периодов для каждой строки.
- Проведение, проверка остатка и отмена подписки с причиной.
- Отчёты по остаткам счетов и выручке по тарифам и клиентам.
- Автоматическое обновление статусов примерно раз в минуту, часовой пояс — `Europe/Moscow`.
- Дашборд: остатки, выручка за текущий месяц, диаграммы за всё время и последние документы.
- Журнал успешных проведений и отмен проведения.

## Как пользоваться

1. Создайте клиента и доступный тариф с ценой и длительностью периода.
2. Создайте и проведите платёж — он пополнит лицевой счёт клиента.
3. Создайте подписку: выберите клиента и добавьте строки с тарифами и количеством периодов.
4. Сохраните документ, проверьте суммы и даты, затем проведите его.
5. Проверьте остаток и выручку в отчётах. Для отмены используйте действие «Отменить подписку» и укажите причину.

## Основные правила

Финансовые движения создаются только при проведении: платёж пополняет счёт, подписка списывает стоимость и признаёт выручку. При нехватке денег операция полностью отклоняется. Повторное проведение не удваивает суммы.

Сумма строки = цена × число периодов. Итог — сумма строк. Дата окончания = дата начала + максимальный срок среди строк, где срок строки = дней в периоде × число периодов. День окончания не включается в срок действия.

Клиент и хотя бы одна строка обязательны, число периодов должно быть положительным, тариф — доступным для подключения. Цена и длительность сохраняются как снимок условий тарифа; деньги рассчитываются через `BigDecimal`. Проведённые финансовые условия защищены от редактирования.

Отмена полностью возвращает стоимость и убирает выручку. Отменённая подписка не имеет активных движений; исторические записи остаются для аудита. При отмене проведённого документа его технический признак «Проведена» сохраняется.

## Тесты

```bash
mvn test
```

Тесты проверяют расчёты, бизнес-правила, проведение, нехватку средств, повторное проведение, отмену, статусы по датам и конкурентное списание. Используется отдельная H2 в памяти — рабочие данные не затрагиваются.

Документация: [onno-framework](https://github.com/onno-erp/onno-framework).
